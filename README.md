## About

Welcome to my **CachyOS-Niri** repository!

This repository contains my personal Linux desktop setup, built around [CachyOS](https://cachyos.org/) and [Niri](https://github.com/niri-wm/niri).

My goal is to create a clean, minimal and functional desktop environment, combining customization, aesthetics and productivity.

- **Compositor:** Niri
- **Display Protocol:** Wayland
- **Terminal:** Kitty
- **Shell Information:** Fastfetch
- **Desktop Customization:** Noctalia

## Installation

These are my personal configuration files.

If you want to use them:

1. Clone or download this repository.
2. Explore the directories.
3. Check the configuration files you want to use.
4. Back up your existing configurations before replacing anything.
5. Adapt the files to your own system.

**Note:** Some configurations may require additional applications or dependencies.
